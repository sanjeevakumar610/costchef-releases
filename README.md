# CostChef apps

Built and published by the private costchef-app repo. Get them from https://costchef-app-le32.vercel.app → More → CostChef app.

- **Android:** [costchef.apk](costchef.apk), version 2.1.32 (open the link on the phone).
- **Windows (the till program):** [CostChef-Setup.exe](CostChef-Setup.exe), version 2.1.32. Windows says "Windows protected your PC": More info → Run anyway, once. It updates itself after the day close.
